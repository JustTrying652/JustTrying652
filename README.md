### 🛠️ What I'm Building

**[Study Buddy Chat](https://study-buddy-red-ten.vercel.app)** — AI study companion, deployed and in active use by classmates
`Next.js` `Vercel AI SDK` `Groq` `Supabase`
Streaming AI chat with auto-generated flashcards/quizzes, spaced-repetition review mode, and file-attachment support for notes.

**[ClimateGuard Kenya](https://climateguard-kenya.vercel.app)** — Real-time disaster management dashboard
`React` `Vite` `Firebase` `Leaflet` `Recharts`
Uses real UNICEF and WFP data across all 47 Kenya counties to track disaster risk.

**Spotify Playlist Merger** — Portfolio project merging playlists & removing duplicates
`Django` `React` `TypeScript` `Spotify Web API`
Full OAuth flow, near-duplicate detection, merge previews, undo, and export — built end-to-end against a real Spotify account.

**Hospital Outbreak Early-Warning System** — Inter-University Hackathon 2026 (JKUAT) entry
Forecasts disease outbreak surges and predicts medicine/bed stock-outs using anomaly detection against historical baselines.
